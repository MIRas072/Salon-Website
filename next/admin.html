Записи

Загружается выбранный период. Поиск работает по загруженным записям.

Смены и перерывы

Разделите смену на интервалы, чтобы добавить обед. Пустой список означает выходной. Изменение дня не затрагивает недельный график.

Клиенты

Карточки создаются по номеру телефона. История и заметки доступны только сотрудникам.

Настройки салона

Услуги

Мастера и услуги

Недельный график

Для каждого мастера: дни 0–6 (0 — воскресенье), интервалы через запятую. Пустое поле — выходной.

Персональные данные

До утверждения политики публичная запись закрыта. Проверьте сроки хранения, права клиентов и применимые требования к размещению данных.

Доступ сотрудников

Сначала создайте пользователя в Firebase Authentication. Скопируйте его UID сюда. Пароль хранит Firebase; передавать его разработчику не нужно.

Журнал действий

Создание и изменение записей, оплаты, график, настройки и доступы.

Экспорт и резервная копия

Экспорт содержит персональные данные. Храните его в закрытом месте. Для восстановления используйте серверный инструмент по инструкции; загрузка файла в браузер данные не восстанавливает.

Экспорт предназначен для небольшой базы. Для больших архивов — серверный экспорт Firebase.
