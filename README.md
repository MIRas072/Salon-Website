# Salon Website

Рабочая статическая версия: корневые HTML/CSS/JS-файлы, инструкции в [SETUP.md](SETUP.md).

Новая система с сервером и базой данных: [SYSTEM-V2.md](SYSTEM-V2.md). Клиент и кабинет в `next/`, Node.js API в `backend/`. Команды: `npm ci`, `npm test`, `npm run test:ui`, `npm run build`, `npm run dev`.

V2 пока не переключена на рабочие данные. Для публикации требуются серверные настройки Firebase, индексы, миграция и проверка владельцем.
